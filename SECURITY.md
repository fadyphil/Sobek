# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | ✅ Yes             |
| < 1.0   | ❌ No              |

## Reporting a Vulnerability

If you discover a security vulnerability within Sobek (either in the Flutter application or the ML pipeline), please do not open a public issue. Instead, report it via the following steps:

1. Email a detailed description of the vulnerability to [your-email@example.com].
2. Include any relevant logs, screenshots, or steps to reproduce.
3. Allow up to 48 hours for a response.

We appreciate your help in keeping Sobek secure and private.
